# Independent Review Boundaries

The reviewer uses the criteria and profiles bundled with this skill. No other audit framework, private document, local tool directory or model-provider account is required.

- Inspect the complete selected target, including unchanged files and references.
- Separate source layout from standalone package closure and public release availability.
- Use independently established command contracts; documentation alone cannot prove runtime support.
- Test with synthetic fixtures. Business execution requires separate authorization and verified isolation.
- Assert actual ordered events, values and outcomes; narrative markers are not execution evidence.
- Preserve existing valid bounded user authorization; clarify missing or changed scope before writes.
- Record missing evidence and unexecuted checks explicitly. A static pass does not prove business acceptance or settlement.
- Store only redacted findings and the minimum evidence required for reproducibility.
