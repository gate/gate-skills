# Affiliate Reporting Workflows

## Relationship, commissions and statistics

1. Read [relationships](relationships-commands.md) for the authorized role and requested subordinate scope. Application reads do not submit an application.
2. Select [commissions](commissions-commands.md) and/or [statistics](statistics-commands.md) for the actual partner/broker/agency metric. Limit users, currencies, date ranges and pagination to the question.
3. Reconcile the same window, role, timezone and currency. Preserve pending/paid/reversed distinctions and explain unavailable fields rather than inventing totals.
4. Report minimum necessary data and definitions; never turn reporting into payout, trading, campaign enrollment or a promise of income.

## Shared stopping rules

Read [preflight](../../_shared/cex/preflight.md), [safety](../../_shared/cex/safety.md) and [execution](../../_shared/cex/execution-cli.md). Keep the same selected account context, credentials, origin and grant throughout. Stop before a step outside verified authority, on changed material terms, or on an ambiguous write. Do not replay earlier steps or automatically compensate. A cross-skill task transfers only the required account/environment, object reference, exact amount/unit, completed state and remaining authority; never credentials.
